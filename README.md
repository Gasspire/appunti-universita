# 🎓 Appunti Università

Benvenuti nel mio repository personale dove raccolgo gli appunti delle lezioni, gli esercizi e il materiale di studio universitario. 

L'intero flusso di lavoro è gestito su **Linux (Ubuntu)** e sincronizzato tramite Git per essere accessibile su più postazioni.

## 🛠️ Stack Tecnologico
Per la gestione di questi appunti utilizzo:
- **[Obsidian](https://obsidian.md/):** Come nucleo centrale per la gestione delle note in Markdown e il personal knowledge management.
- **[LaTeX](https://www.latex-project.org/):** Per la stesura di documenti formali, formule matematiche complesse e la tesi.
- **[Xournal++](https://xournalpp.github.io/):** Per prendere appunti a mano libera o annotare PDF, integrando formule LaTeX nei disegni.
- **VS Code:** Come editor secondario per la compilazione LaTeX e la gestione del repository.

## 📂 Struttura del Repository
Il repository è organizzato in cartelle per materia. Ogni cartella contiene:
- Note in formato `.md` (Obsidian).
- Eventuali sorgenti `.tex` per documenti o relazioni.
- Allegati e immagini relativi agli argomenti trattati.

## ⚠️ Disclaimer (Importante)
Questo repository è una raccolta di appunti personali presi durante le ore di lezione o durante lo studio individuale. 

> **Nota bene:** Gli appunti **possono contenere errori** di battitura, imprecisioni concettuali o sviste matematiche. Non sono da considerarsi materiale didattico ufficiale o verificato dai docenti. Se decidi di utilizzarli per il tuo studio, fallo con spirito critico e verifica sempre le informazioni sulle fonti ufficiali.
